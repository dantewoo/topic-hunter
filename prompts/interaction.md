# 交互层话术

## 开场

当用户触发选题 Skill 时，按以下流程与用户交互。原则：一条消息问完，用户一次回复就能开始；聊天界面发不出空消息，所以不要让用户“直接回车”。

---

## 标准流程（一次问完）

向用户展示：

```
选一下这次的选题偏好，一次回复即可，格式：领域 / 形态 / 受众，例如“1,2 / 2 / 4”。
回复“默认”就用括号里的默认值。

领域（可多选）：
1  科技/AI    — 新技术、产品发布、行业变动
2  商业/财经   — 公司动态、市场趋势、搞钱逻辑
3  社会/民生   — 热点事件、政策变化、群体现象
4  娱乐/文化   — 影视综艺、名人动态、流行梗
5  游戏/二次元  — 新游、赛事、圈层文化
6  健康/生活   — 养生、心理学、生活方式
7  知识/科普   — 冷知识、硬核解释、认知升级
8  混合/不限   — 全领域扫描，看什么能爆就推什么（默认）

形态（单选）：
1  短视频（抖音/快手）  — 14字标题，30秒-3分钟（默认）
2  图文（公众号/小红书） — 标题+封面逻辑
3  播客/长视频         — 深度内容，节奏不同

受众（单选）：
1  科技从业者/爱好者   — 追前沿，爱硬核，能看深度
2  创业者/投资人        — 要信息差，要判断依据
3  大学生/年轻群体      — 追热点，爱玩梗，注意力短
4  普通大众/下沉市场   — 共情驱动，要看得懂（默认）
5  知识型受众           — 认知升级驱动，愿意看完
```

解析规则：
- 按“/”分成三段；只回了一两段，缺的部分用默认值。
- 用户用文字回答（如“科技和财经，公众号，普通人”）时按意思匹配，不要求必须是数字。
- 某一段无法识别时，只追问这一段，其余照用户的回答。

## 特殊流程

### 快速模式（用户说“选题 快”）

跳过交互。有偏好文件就用偏好，没有就用默认值（混合/不限 / 短视频 / 普通大众）。

告知用户：
```
快速模式：科技/AI、商业/财经 / 图文 / 普通大众（沿用上次偏好）
开始搜索...
```

### 指定领域模式（用户说“选题 科技”）

跳过领域选择，使用用户指定的领域。形态和受众有偏好用偏好，没有用默认值。

告知用户：
```
指定领域：科技/AI
形态和受众：图文 / 普通大众（沿用上次偏好）
开始搜索...
```

### 老用户模式（有偏好文件）

```
上次的偏好：科技/AI、商业/财经 / 图文 / 普通大众
回复“好”沿用，或直接说要改的项，如“形态改短视频”。
```

用户输入规则：
- “好”“行”“沿用”“可以”等确认：沿用上次偏好
- 说了要改的项：只改这一项，其余沿用
- 说“重新选”：走标准流程

### 评估模式（用户给出候选，问哪个能做）

不走上面的交互。形态和受众有偏好用偏好，没有用默认值，在输出开头写明本次按什么形态和受众评估。
